# glEYEco Galectin-3 Computational Validation (Progress)

Currently, the folder holds the first step of the glEYEco project. The goal was to use real glycan binding databases to answer two questions before doing any wetlab work:

1. Are the right glycans actually present at the eye surface? (Ex: does the cornea have enough Core 1 O-glycans for Gal-3 to grab onto)
2. Will Gal-3 bind the right ones and not the wrong ones? (Ex: will it stick to corneal mucins but leave ECM proteins and ubiquitous N-glycans alone)

Everything is in: galectin3_analysis.ipynb
The other files are outputs from that notebook or archived older work.

# The two databases the notebook uses

- `df_glycan` (~50,500 glycan sequences) — a catalogue of known glycan structures with tissue and disease associations. Used to answer: *which glycans exist at the eye?*
- `glycan_binding` (~2,100 proteins × 2,900 glycans) — experimental binding scores from glycan microarray data. Used to answer: *what does Galectin-3 actually bind?*

One thing to know: these two databases don't always use the same naming conventions for glycans, so direct matches between them often come up empty. When that happens the notebook falls back to motif-level searching (e.g. "count how many ocular glycans contain the pattern `Gal(b1-3)GalNAc`") which is still meaningful.

# On-target vs off-targets (Results)

| Class | Glycan | Why it matters |
|-------|--------|----------------|
| **On-target** | Core 1 O-Glycan `Gal(b1-3)GalNAc` | The mucin O-glycan Gal-3 should anchor to on the corneal surface |
| Off-target | LacNAc `Gal(b1-4)GlcNAc` | Extremely common — shows up in almost every N- and O-glycan in the body |
| Off-target | Fibronectin / Laminin N-glycans | ECM proteins in the stroma — non-specific binding here = unintended retention |
| Off-target | Galactosylated bi-antennary N-glycan | The most common complex N-glycan structure; carries LacNAc arms |
| Neg ctrl | Tn Antigen `GalNAc` | The biosynthetic step *before* Core 1 — no Gal attached, Gal-3 shouldn't bind this |

# How to run it

Install dependencies (one-time):

```bash
pip install glycowork
pip install "glycowork[ml]"     # only needed for Section 4 (LectinOracle predictions)
pip install "glycowork[chem]" rdkit   # only needed for Section 5 (SMILES + 3D structures)
```

Open the notebook:

```bash
jupyter notebook galectin3_analysis.ipynb
```

Run all cells top to bottom. Sections 4 and 5 have optional dependencies — the notebook checks for them and skips gracefully if they're not installed.

# What each section of the notebook does

Section 1  Setup: installs packages, imports everything.

Section 2  Validate target tissue:** searches `df_glycan` for glycans tagged to eye/cornea/lacrimal tissue. Finds ~134. Breaks them down by type and checks which ones carry β-galactoside linkages (the motif Gal-3 recognises).

Section 3  Gal-3 specificity and off-target risk: rebuilt into two parts. Part 1 (complete) pulls the full Gal-3 binding profile from `glycan_binding`, defines the on-target (Core 1 O-glycan), four off-target classes (LacNAc, bi-antennary N-glycan, ECM glycans, Tn Antigen), and quantifies each one two ways — first by motif prevalence in the ocular tissue subset of `df_glycan`, then by searching for the same structural motifs inside the `glycan_binding` column names to pull actual microarray scores. This sidesteps the IUPAC naming gap between the two databases. Section 3.8 remains the on-target vs off-target summary chart. Part 2 is a scaffold for fusion protein binding validation — no code yet, waiting on the final fusion protein sequence.

Section 4  LectinOracle (optional): an ML model that predicts binding scores for a custom protein sequence. Useful once you have an engineered fusion protein sequence to test.

Section 5  Structures for docking: converts glycan names (IUPAC strings) → SMILES → 3D `.pdb` files. The four simple glycans generate fine; the large biantennary N-glycan needs to be done manually through [GLYCAM-Web](https://glycam.org/cb).

### Section 2.1 - Where? Confirming the Corneal Epithelium as the Target Site
- We started with tissue validation because empirical glycan documentation is only meaningful within its target issue. By identifying a binding target in a database without confirming its presence in the relevant biological environment is an assumption rather than evidence. Therefore we need to first validate whether the database we are using has documented data of the tissue we are looking at.
- As such, we search `df_glycan` for all entries annotated to eye, cornea, tears, lacrimal gland, lens, and conjunctiva. This search results in 134 unique glycan sequences which validates the database we are using as sufficient enough to distinguish glycans. 

### Section 2.2 - What? Establishing that O-glycans are dominate 
- With the tissue pool established, we then have to ask ourselves which glycan is most dominate in the Corneal Epithelium since the class determines the lectin family. An N-glycan rich surface would point towards N-glycan Binding Lectins whereas an O-glycan rich surface would infer mucin O-glycan readers like Gale-3. 
- Previous literature establishes the Corneal Epithelium as heavily mucin-glycosylated (MUC1, MUC4, MUC16 are all present), and the database confirms O-glycans are the dominant class in the ocular subset. 

### Section 2.3 - Why? Justifying the choice of Core1 T-Antigen on MUC1 Thr86
- When choosing between the O-glycans present, our team considered three critical criterion. The glycan needs to be naturally abundant, exposed on the surface, and includes a high binding affinity to Gal-3. Core 1 T-antigen (Gal(b1-3)GalNAc) satisfies all three criterion and is experimentally proven. 
- Core 1 T-antigen is the dominant O-Glycan on MUC1 Thr86. It is also surface-exposed and the most studied transmembrance mucin of the ocular surface. Its two-sugar structure allows easy recognizable for Gal-3, which helps with high binding affinity, ultimately being a well documented lectin-glycan interaction.
